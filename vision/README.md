# computer vision

planned topics and study notes for 2d image processing, detection and tracking.

## topics to be covered

- **image processing** — image transformations, convolutions, filtering, histograms and color spaces
- **edge and corner detection** — gradient operators, sobel, canny edge detector and harris corner detector
- **feature extraction** — keypoint detectors, local feature descriptors and robust feature matching
- **optical flow** — brightness constancy assumption, lucas kanade, horn schunck and deep optical flow
- **object detection** — bounding box regression, anchor based and anchor free modern object detectors
- **image segmentation** — semantic segmentation, instance segmentation and panoptic segmentation
- **visual tracking** — single object tracking, multi object tracking, kalman tracking and re-identification
- **aerial image analytics** — drone video analysis, high resolution aerial imagery and small object detection
- **dataset engineering** — image labeling pipelines, data augmentation techniques and cross validation
