# robotics

planned topics and study notes for kinematics, dynamics, ros 2 and simulation.

## topics to be covered

- **kinematics** — forward and inverse kinematics, transformation matrices, jacobian matrices and singularities
- **rigid body dynamics** — euler lagrange equations, newton euler formulation and spatial inertia tensors
- **actuator dynamics** — electric motor models, torque speed curves, gearboxes and transmission dynamics
- **robot modeling** — urdf, xacro macros, joint limits, inertial properties and visual collision meshes
- **ros 2 core** — computational graph, nodes, topics, publishers, subscribers, services and actions
- **ros 2 configuration** — launch architecture, parameter management, component composition and lifecycle nodes
- **transform library** — tf2 coordinate transformations, static broadcasters, buffer lookups and time travel
- **gazebo simulation** — rigid body physics engines, contact dynamics, sensor simulation and world creation
- **isaac sim** — omniverse physics, gpu accelerated parallel simulation, synthetic data and sensor pipelines
