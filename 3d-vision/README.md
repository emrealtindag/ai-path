# 3d vision

planned topics and study notes for geometry, reconstruction and spatial representations.

## topics to be covered

- **camera models** — pinhole camera geometry, perspective projection, intrinsic and extrinsic matrices
- **camera calibration** — zhang calibration method, radial and tangential lens distortion correction
- **epipolar geometry** — stereo baseline, epipolar planes, essential matrix and fundamental matrix
- **two view geometry** — essential matrix decomposition, singular value decomposition and triangulation
- **structure from motion** — incremental and global sfm pipelines, feature tracks and bundle adjustment
- **pose estimation** — perspective n point algorithms, epnp, p3p and robust ransac estimation
- **depth estimation** — stereo disparity matching, cost aggregation and monocular depth prediction
- **point cloud processing** — open3d, voxel grids, normal estimation, filtering and iterative closest point
- **geometric optimization** — non linear bundle adjustment, reprojection error and pose graph optimization
- **neural 3d representations** — neural radiance fields, volume rendering and 3d gaussian splatting
