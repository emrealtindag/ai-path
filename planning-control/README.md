# planning and control

planned topics and study notes for trajectory planning, optimal control and autonomous navigation.

## topics to be covered

- **classical feedback control** — transfer functions, root locus, pid control, windup prevention and tuning
- **state space control** — state feedback, controllability, observability, pole placement and lqr control
- **model predictive control** — receding horizon control, state constraints, input constraints and quadratic programming
- **grid based path planning** — dijkstra algorithm, a star, heuristic design, d star and dynamic replanning
- **sampling based planning** — probabilistic roadmaps, rrt, rrt star and asymptotic optimality
- **kinodynamic planning** — motion planning subject to velocity, acceleration and differential constraints
- **trajectory optimization** — minimum jerk trajectories, minimum snap optimization and polynomial splines
- **dynamic obstacle avoidance** — local trajectory replanning, signed distance fields and reactive maneuvers
- **swarm coordination** — multi agent trajectory deconfliction, formation control and decentralized planning
