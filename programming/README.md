# programming

systems programming, modern c++, scientific computing, and high-performance engineering.

---

## tracks

### [modern c++](./cpp/)

foundations, memory architecture, object-oriented design, and systems engineering in modern c++:

1. **[01-variables-data-types-operators](./cpp/01-variables-data-types-operators/)**: fundamental types, byte layouts, type casting, arithmetic, standard i/o streams, and iomanip formatting.
2. **[02-conditions](./cpp/02-conditions/)**: relational operators, boolean logic, short-circuit evaluation, if-else chains, and switch-case jump tables.
3. **[03-loops](./cpp/03-loops/)**: while, do-while, for loops, state trace tables, loop counters, break/continue flow control, and nested loops.
4. **[04-strings](./cpp/04-strings/)**: char primitives, std::string container, memory indexing, iteration patterns, and getline stream reading.

## roadmap and upcoming topics

- **python** — scientific computing, automation, numpy, scipy and scripting
- **memory management** — pointers, references, stack versus heap and raii principles
- **smart pointers** — unique pointers, shared pointers, weak pointers and custom deleters
- **move semantics** — rvalue references, std::move, move constructors and perfect forwarding
- **standard template library** — stl containers, iterators, function objects and algorithms
- **cmake build system** — target based cmake, compiler flags, libraries and external dependencies
- **eigen library** — matrix and vector representations, matrix algebra and geometry modules
- **concurrency** — multithreading, mutexes, locks, atomic operations and condition variables
- **performance profiling** — cache friendly data structures, memory profiling and benchmarking
- **gpu programming** — cuda programming model, kernels, thread blocks, shared memory and streams
