# modern c++

foundations, memory architecture, data structures, and systems programming in modern c++.

---

## module index

the fundamentals track covers core language syntax, type systems, control flow, loops, and string processing derived from university course notes and production standards:

1. **[01-variables-data-types-operators](./01-variables-data-types-operators/)**: fundamental types (`int`, `double`, `float`, `char`, `bool`), byte sizes, type casting (`(double)` and `static_cast`), arithmetic operators, standard streams (`std::cin`, `std::cout`), and output formatting (`<iomanip>`, `<cmath>`).
2. **[02-conditions](./02-conditions/)**: relational comparisons, boolean algebra (`&&`, `||`, `!`), short-circuit evaluation, conditional branching (`if`, `else if`, `else`), and multi-way jump tables (`switch`, `case`, `break`, fall-through).
3. **[03-loops](./03-loops/)**: pre-condition iteration (`while`), post-condition iteration (`do-while`), counter loops (`for`), state tracing tables, loop variables, accumulator patterns, jump statements (`break`, `continue`), and nested loops.
4. **[04-strings](./04-strings/)**: primitive `char` vs `std::string`, stack/heap contiguous storage, zero-based indexing (`str[i]`), traversal methods, and line extraction (`std::getline`).
