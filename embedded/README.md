# embedded systems

planned topics and study notes for microcontrollers, firmware, and real-time execution.

## topics to be covered

- **microcontroller architectures** — arm cortex-m series, register layouts, flash memory and sram
- **bare metal and embedded c** — volatile keyword, memory mapped input output, bit manipulation and linkers
- **interrupt handling** — nested vectored interrupt controller, isr latency and direct memory access channels
- **serial communication buses** — uart protocol, baud rate generation, spi bus modes and i2c transactions
- **controller area network** — can bus physical layer, differential signaling, message frames and arbitration
- **real time operating systems** — freertos kernel, priority preemptive scheduling, task states and contexts
- **inter task communication** — freertos queues, binary semaphores, counting semaphores and event groups
- **real time execution** — deterministic task deadlines, jitter minimization, task starvation and watchdog timers
- **driver architecture** — hardware abstraction layers, sensor device drivers and peripheral initialization
