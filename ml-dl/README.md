# machine learning and deep learning

planned topics and study notes for statistical learning, neural networks and robot learning.

## topics to be covered

- **statistical learning** — empirical risk minimization, bias variance tradeoff, linear and logistic regression
- **classical machine learning** — decision trees, random forests, boosting methods and support vector machines
- **autograd from scratch** — computational graphs, automatic differentiation and backpropagation implementation
- **neural network fundamentals** — multi layer perceptrons, activation functions, loss functions and weight initialization
- **convolutional networks** — 2d convolutions, pooling, residual connections and feature extraction
- **attention and transformers** — self attention, multi head attention, transformer encoders and vision transformers
- **representation learning** — contrastive learning, self supervised representations and foundation vision models
- **deep learning workflows** — pytorch dataset loaders, model architectures, training loops and evaluation
- **probabilistic graphical models** — bayesian networks, markov random fields, factor graphs and inference
- **reinforcement learning** — markov decision processes, value iteration, policy gradients and actor critic methods
- **robot learning** — imitation learning, behavioral cloning, dataset aggregation and modern policy architectures
