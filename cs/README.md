# computer science

planned topics and study notes for systems, architecture, and core cs.

## topics to be covered

- **data structures** — arrays, linked lists, trees, graphs, heaps and hash maps
- **algorithms** — sorting, graph traversal, search algorithms and dynamic programming
- **computer architecture** — cpu architecture, datapath, control units and instruction sets
- **memory hierarchy** — registers, l1 l2 l3 cache hierarchy and cache coherence
- **system bus and ram** — memory bus architecture, ram bandwidth and memory latency
- **processor optimization** — instruction pipelining, pipeline hazards and branch prediction
- **vector computing** — simd architectures and compiler vectorization
- **gpu architecture** — streaming multiprocessors, warps and gpu memory hierarchy
- **heterogeneous computing** — cpu to gpu communication, pcie bandwidth and transfer latency
- **operating systems** — processes, threads, virtual memory, memory management and concurrency
- **computer networks** — network protocols, sockets and data distribution service
- **software engineering** — git version control, ci cd pipelines, testing and linux tooling
