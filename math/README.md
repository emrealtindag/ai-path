# math

planned topics and study notes for mathematics and numerical optimization.

## topics to be covered

- **linear algebra** — vector spaces, matrix operations and matrix decompositions
- **spectral theory** — eigenvalues, eigenvectors and singular value decomposition
- **multivariate calculus** — partial derivatives, gradients, jacobians and hessians
- **probability theory** — random variables, probability distributions and bayes theorem
- **gaussian models** — multivariate normal distributions and covariance matrices
- **differential equations** — ordinary differential equations and state space representations
- **numerical methods** — root finding, numerical differentiation and numerical integration
- **numerical optimization** — unconstrained optimization, gradient descent and newton methods
- **nonlinear least squares** — curve fitting, gauss newton and levenberg marquardt
- **discrete mathematics** — combinatorics, graph theory and graph search algorithms
- **signal processing** — fourier transform, laplace transform and frequency domain analysis
- **lie theory** — lie groups and lie algebras on so3 and se3 manifolds for 3d rotation and translation
